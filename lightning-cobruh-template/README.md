# Lightning-Cobruh Template

A clean template to kickstart your deep learning project using PyTorch Lightning and Cobruh for configuration management! 🚀⚡🔥

Inspired by [lightning-hydra-template](https://github.com/ashleve/lightning-hydra-template), but using Cobruh instead of Hydra for configuration management.

## Features

- 🏗️ **Hierarchical Configuration** - Cobruh-based config composition
- ⚡ **PyTorch Lightning** - Organized training loops and best practices
- 🔄 **Modular Design** - Easy to extend and modify
- 🖥️ **CLI Overrides** - Override any config value from command line
- 📊 **Experiment Tracking** - Built-in logger support (TensorBoard, CSV, etc.)
- 🧪 **Testing** - Comprehensive test suite included
- 📝 **Well Documented** - Extensive comments and docstrings

## Quick Start

### Installation

```bash
# Clone the template
git clone <repository-url>
cd lightning-cobruh-template

# Install dependencies
pip install -r requirements.txt

# Install project as package
pip install -e .
```

### Training

```bash
# Train with default config
python src/train.py

# Train on GPU
python src/train.py trainer=gpu

# Override config options from command line
python src/train.py trainer.max_epochs=20 data.batch_size=64

# Train with experiment config
python src/train.py experiment=example
```

### Evaluation

```bash
# Evaluate with checkpoint
python src/eval.py ckpt_path="/path/to/checkpoint.ckpt"
```

## Configuration

The template uses Cobruh for hierarchical configuration management. All configs are stored in the `configs/` directory.

### Main Config (`configs/train.yaml`)

```yaml
defaults:
  - data: mnist.yaml
  - model: mnist.yaml
  - callbacks: default.yaml
  - logger: null
  - trainer: default.yaml
  - paths: default.yaml
  - extras: default.yaml

task_name: "train"
tags: ["dev"]
train: True
test: True
seed: null
```

### Experiment Configs

Create experiment configs in `configs/experiment/` to version control hyperparameters:

```yaml
# @package _global_

defaults:
  - override /data: mnist.yaml
  - override /model: mnist.yaml

tags: ["mnist", "experiment_1"]

trainer:
  max_epochs: 10

model:
  optimizer:
    lr: 0.001
```

## Advanced Usage

### Creating Custom Models

1. Create model config in `configs/model/`:

```yaml
_target_: src.models.my_module.MyLitModule

optimizer:
  _target_: torch.optim.Adam
  _partial_: true
  lr: 0.001

net:
  _target_: src.models.components.my_net.MyNet
  # your model parameters
```

2. Implement the Lightning Module in `src/models/`:

```python
from lightning import LightningModule

class MyLitModule(LightningModule):
    def __init__(self, net, optimizer, ...):
        super().__init__()
        self.save_hyperparameters()
        self.net = net
        # implementation...
```

### Creating Custom Data Modules

1. Create data config in `configs/data/`:

```yaml
_target_: src.data.my_datamodule.MyDataModule

data_dir: ${paths.data_dir}/my_data
batch_size: 32
# your data parameters
```

2. Implement the Lightning DataModule in `src/data/`:

```python
from lightning import LightningDataModule

class MyDataModule(LightningDataModule):
    def prepare_data(self):
        # download, etc.
        pass

    def setup(self, stage):
        # load data, split, etc.
        pass
    
    def train_dataloader(self):
        # return train loader
        pass
```

## CLI Examples

```bash
# Train on CPU with custom batch size
python src/train.py trainer=cpu data.batch_size=128

# Train on GPU with mixed precision
python src/train.py trainer=gpu trainer.precision=16-mixed

# Debug with fast dev run
python src/train.py debug=fdr

# Override optimizer learning rate
python src/train.py model.optimizer.lr=0.0001

# Add tags to experiment
python src/train.py tags=["experiment1","test"]
```

## Differences from Hydra Template

This template uses **Cobruh** instead of Hydra:

- ✅ Native Python configuration with type hints
- ✅ Simpler configuration structure
- ✅ Better IDE support
- ✅ Lightweight and focused on essentials
- ✅ Compatible with Python 3.10+
