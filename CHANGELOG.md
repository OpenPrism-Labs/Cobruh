# Changelog

## 0.2.0

- Replaced global wrapper APIs with the explicit `Cobruh` project object and ordinary Python mappings.
- Added deterministic YAML defaults, sequential overrides, interpolation, provenance, and recursive target instantiation.
- Added the `cobruh` CLI, optional trusted local MCP server, and bundled portable Agent Skills.
- Fixed wheel package discovery and declared CPython 3.10 through 3.14 support.
- Removed the unsupported Hydra/OmegaConf compatibility surface and stale Lightning template.
