# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial implementation of Cobruh configuration framework
- Core configuration containers (DictConfig, ListConfig)
- Configuration composition engine with YAML support
- Defaults list processing for hierarchical configs
- Command-line override support
- Main decorator for easy application integration
- Programmatic compose API
- ConfigStore for registering config schemas
- Object instantiation utility
- Support for Python 3.10+
- Comprehensive test suite
- Example applications
- Complete documentation

## [0.1.0] - 2025-10-25

### Added
- Initial alpha release
- Basic configuration management functionality
- YAML file loading
- Dot-notation access to configs
- Type-safe configuration with OmegaConf integration
